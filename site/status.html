Is this project maintained?

The registry is kept up by four scheduled jobs in the public repository. This page says when each runs, what the repository records about the last months, where to see live results, and how to follow changes. It states only what the committed files show.

What runs and when

Times are as the schedule is written in the workflow files. GitHub can start a scheduled job late, and a job can fail; the sections below say what the record shows, not what was meant to happen.

Evidence search

Monthly, on the 1st, from 06:00 UTC

Searches the open scholarly indexes for new psychometric literature on every instrument in the registry and opens one issue for the month. It lists candidate works to be read. It changes no dataset, no grade and no page.

Run history on GitHub · Open issues labelled evidence-sweep

Corrections and retractions check

Monthly, on the 2nd, from 07:00 UTC

Checks every DOI the registry cites for correction, expression of concern, retraction or withdrawal notices, and opens an issue naming the work and the records that cite it if it finds one. Nothing is removed or regraded automatically.

Run history on GitHub · Open issues titled Retraction watch

Monthly verification

Monthly, on the 3rd, from 08:00 UTC

Checks that the month's evidence search really happened and finished. If it did not, it opens one issue for the month that names the month and the one action needed, so a missed month is noticed rather than silent.

Run history on GitHub · Open issues labelled maintenance

Licence check

Weekly, on Mondays, from 07:00 UTC

Fetches every licence page the registry cites and compares it with the recorded baseline. It reports a change, or a page it could not check, in one standing issue. It never edits a licence class; a person reads the page.

Run history on GitHub · Open issues labelled licence

Where to see live results

  • All workflow runs on GitHub, newest first.
  • Open issues the jobs raise: evidence-sweep, maintenance, licence.

The grey "last run" lines above come from GitHub's public API. When you open this page, your browser asks api.github.com for the latest run of each job; GitHub receives your IP address as any site you visit does, and nothing is sent or stored by us. If your browser blocks the request or GitHub does not answer, the lines do not appear and the rest of the page is unchanged. They show the latest run of any kind, including one started by hand, so read them with the run history. See the privacy page.

Follow

There is no email sign-up and this site collects no addresses. Ways to follow without one:

  • Feeds (Atom, for a feed reader). Each entry carries the date the changelog or report gives it.
    • All changes: registry, specification and site (feed.xml)
    • Registry changes (feed-registry.xml)
    • Specification changes (feed-specification.xml)
    • Site changes (feed-site.xml)
    • Monthly evidence sweep reports (feed-sweeps.xml)
  • The changelog on this site: every change to the registry, the specification and the site, newest first.
  • On GitHub, for developers: open the repository, choose Watch, then Custom, then Releases, to be told when a tagged release is published. Choose Issues or Pull requests as well to follow discussion. Tagged releases are listed on the releases page.
