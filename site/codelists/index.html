Code lists

The 27 controlled vocabularies the schemas pin by name and version, 141 codes in all, listed from the files themselves. Each list is published as raw JSON; every released version of a list is kept.

Each code list is versioned independently of the spec (semver). Schemas pin a list by name@version. Each entry's versions map names the file for every released version of the list, so a schema pinned to an older version resolves to the preserved artefact rather than to the current file; archived files under codelists/archive/ are never edited. The specification's code lists section says which fields use which list. The schemas have their own page. The crosswalk files in mappings/ map one list to an external classification; they are not code lists.
