How to cite OWHS

Each part of OWHS is cited by its version number and its address. There is no DOI yet. No archived release has been made, so none has been issued, and this page will say so when that changes. The repository also carries a CITATION.cff file, which GitHub reads to offer a citation for the repository as a whole.

Add the date you accessed the page to any reference. The three works below are different things with their own versions: the specification, the registry dataset and the question bank.

Open Workplace Health Standard (2026). OWHS Instrument Evidence Base. Version 0.9.0, 3 September 2026. https://openworkplacehealth.org/instrument-registry/

Caveat that the registry itself publishes. Every grade was assigned by one rater employed by the steward (1 rater, 0 independent raters), and grades and statuses are frozen until two named psychometric raters who are not employees of the steward have joined. Grades are not a recommendation and are not comparable across instruments. The dataset is schema 0.7, graded under rubric 1.6. The file is at https://openworkplacehealth.org/instrument-registry/instrument-evidence-base-v0.9.0.json.

This version was changed in place. The changelog records changes made inside version 0.9.0 without a new version number (latest 19 November 2026: see the registry tab). A version number alone therefore does not fix the content: add the date you accessed it, and for exact reproduction quote the commit of the repository you used. Dates of in-place changes: 19 November 2026.

What a citation does and does not say

Citing a version records which document or dataset you used. It does not mean the thing is endorsed, certified or final. The specification is a draft. The registry's grades are single-rater and are not a recommendation. Where you rely on a specific grade, licence class or item, cite the page for that record and the date you read it.

To report something wrong in what you cite, see the corrections process or how to contribute.
