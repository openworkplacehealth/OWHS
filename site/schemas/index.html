JSON Schemas

Every JSON Schema the Open Workplace Health Standard publishes, listed from the schema files themselves: 20 entity and envelope schemas across v0.1 and v0.2, plus the profile envelope and the evidence-maintenance schemas. Each schema is published as raw JSON at the address in its $id.

The specification defines what each entity means and how the schemas are used; these files are its machine-checkable form. Read JSON Schemas and validation in the specification, and the entity list for a plain-language tour. The versioned catalogue is schemas/catalogue.json. The matching code lists have their own page.
