# Evaluation fixtures

Synthetic inputs for `tools/measure_recall.py`, generated by `python tools/measure_recall.py --write-fixtures evidence/evaluation-tests` and checked byte for byte by its self-test: 33 fictitious works split by the declared deterministic algorithm (23 development, 10 holdout), four holdout works of interest, three retrieved; a synthetic query configuration with a provider profile; coverage rows with lookup provenance; a candidates file in the harvester's own envelope shape (route tags `route:source:instrument`, a predeclared evaluation id); a query lock naming a fixture harvester commit and tool hashes; and an execution record agreeing with them. They exercise the typed contracts in `evidence/evaluation-contracts/` and the accounting; they carry no real judged relevance, no real gold list and no real run. The real judged manifest is private until the evaluation has run and a neutral report is reviewed.
